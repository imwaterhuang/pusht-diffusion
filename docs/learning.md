# 学习实现路线

你拥有新模型和训练算法。工程已给出输入输出边界；本文件描述要满足的行为，不给出完整模型或训练答案。

## 1. 先确认一个训练窗口

从 `PushTDataset` 取回合第一条和末个有效起点。画出 `o_(t−1),o_t → a_t,…,a_(t+15)`。检查首帧重复、尾部动作重复、掩码和二维绝对目标坐标。批次由默认 `DataLoader` 叠为 `[B,2,3,96,96]`、`[B,2,2]`、`[B,16,2]`、`[B,16]`。

通过条件：能说清楚为什么终止行不提供标签、为什么填充动作仍存在于张量里，以及为什么它们不能进入监督损失。

## 2. 观测编码器

在 `learner/models.py` 的 `ObservationEncoder` 中实现：两帧共用一个 ResNet-18（Residual Network，残差网络），每帧保留 `[512,3,3]` 空间网格，展平后投影256维，层归一化和激活，与该帧位置拼接，最后按时间展平为516维。视觉骨干参与学习，批归一化的运行统计固定。

通过条件：能追踪批、时间、通道、空间维度；改变位置或图像会影响条件表示；首次建立训练模型可加载预训练权重，重载完整检查点应不联网下载。

## 3. 时间编码和 U-Net

`k` 是扩散噪声步，`t` 是环境时间；不要复用一个变量解释两种概念。实现时间编码、条件残差块，再实现 U-Net（U-shaped Network，U 形网络）。通道和时间长度依次为128×16、256×8、512×4。解码器先上采样到8或16，再拼接同分辨率跳跃连接。

通过条件：输入带噪动作 `[B,16,2]`、`k [B]`、观测 `[B,516]`，输出预测噪声 `[B,16,2]`；没有时间轴与坐标轴互换；梯度可穿过观测条件和时间条件。

## 4. 训练目标与更新

由你在 `learner/training.py` 实现随机采噪声步、加噪、预测噪声及带掩码的 MSE（Mean Squared Error，均方误差），再实现反向传播、裁剪、AdamW（Adaptive Moment Estimation with Decoupled Weight Decay，解耦权重衰减自适应矩估计）、学习率、EMA（Exponential Moving Average，指数移动平均）和正式循环。调度器的训练加噪可调用库接口，如何接入由你编写。

通过条件：填充位置不贡献损失；分母按有效二维坐标计数；全无效批次明确报错；非有限损失或梯度停止并保留诊断；只有更新成功才推进学习率、平均参数和已消费批次游标。

检查点序列化已实现，但不代表训练恢复已验证。你补齐更新后再运行“同设备连续更新”和“保存恢复后更新”的对照，比较模型、优化器、学习率、平均参数、采样位置与随机数流。

## 5. 小规模诊断，然后完整实验

你实现训练入口后，先自行写固定16窗口、固定噪声与扩散步的小批诊断。损失下降仅证明拟合链路；再使用64窗口和随机噪声诊断，保留固定探针和采样动作。然后运行5个独立调试场景验证闭环。诊断不是正式成绩。

两种模型都走通后，再在 L4 测量更新耗时、加载耗时、峰值显存、20步推理耗时、完整评测与保存耗时。总预算含训练期评测。冻结两种骨干相同的训练工作量，再启动正式训练。

## 6. 替换成动作 DiT

DiT（Diffusion Transformer，扩散 Transformer）把16个动作时刻作为16个表示向量；隐藏256维，6层、8头，前馈1024维。固定时间位置编码；非因果自注意力；观测与扩散时间经 adaLN-Zero（Adaptive Layer Normalization with Zero Initialization，零初始化自适应层归一化）注入。它是动作去噪器，不使用图像生成模型预训练权重。

通过条件：无需修改数据、公共采样器和评测器，只换骨干；记录参数量、耗时与显存。零初始化可能使第一步部分上游梯度为零，应观察多次更新的通路，不据此立即判断实现错误。

## 完成后的实际模型检查

目前 `tests/test_sampling.py` 的零输出对象只是接口桩，没有学习能力。模型完成后，应由你增加真实模块检查：形状、有限数值、观测和时间条件的影响、有效梯度、同噪声重载一致性。`check-ownership` 是交付时的边界审计；你开始实现后它按设计会失败，不应阻止你编写代码。

## 用户补齐后直接运行的检查

```bash
# 使用 README 中的解释器和 PYTHONPATH。
"$PUSHT_PY" -m pytest tests/test_learner_contract.py -q
```

现在三个检查明确跳过，因为模型构造和损失入口未实现；没有自动替换模型。完成后分别检查两种真实模型的观测条件、噪声输出、有限数值、位置条件连通性和保存重载一致性，以及你实现的损失对无效非有限填充值的排除。此处不会代写反向传播或优化器更新。

随后你需要完成这些尚待验收的步骤：

- 在自己的训练步中记录有限损失；确认有效标签变化会改变损失，而填充标签变化不会改变它。
- 反向传播后检查去噪器、时间条件与观测编码参数的梯度。区别“数值为零”与“没有梯度连接”；DiT 零初始化下首次部分梯度为零可以是预期。
- 设置固定的16窗口小批诊断，再进行随机噪声的64窗口诊断，分开记录证据。
- 在相同设备及确定性设置下，用实际模型、优化器、学习率与平均参数分别做连续短训练和保存后恢复短训练，比较同一步全部张量、缓冲区、学习率、已消费游标及随机数状态。
- 恢复时先构建模型、优化器和数据加载器/迭代器，再恢复需要精确延续的随机数流，避免构建对象或新迭代器消耗保存点之后的随机数。当前无随机增强；若以后加入工作进程内随机增强，还必须定义其可恢复随机状态。
- 在固定观测、固定场景噪声下对比保存前后完整采样动作，再完成实际短闭环。仅权重可重载不足以证明正式训练恢复。

`PUSHT_DELIVERY_AUDIT=1` 才启用自动测试中的全部占位审计；默认测试不会要求你永远保留占位。`python -m pusht_diffusion check-ownership` 仍是显式交付审计入口。
