日期：2026-09-24。通过 Codex 内置浏览器实际操作 `http://127.0.0.1:7861/live`，使用已加载的 ACT（Action Chunking with Transformers）策略。以下是交互工程检查，不能作为正式策略效果或扩散模型正确性的证据。

| 操作 | 页面实际观察 |
|---|---|
| 初始连接 | 显示“本地仿真已连接”，ACT 已加载，初始暂停，种子0、步数0 |
| 继续运行 | 场景和步数持续更新；观察到超过22,500步，说明试玩没有在300步强制停止 |
| 暂停 | 按钮变为“继续运行”，停止推进环境步数 |
| 鼠标拖动 T 块 | 暂停时将物块从目标附近拖开；覆盖率从93.4%变为12.4%，步数保持22,521 |
| 重放此场景 | 种子恢复为原种子0，步数0，规划耗时0，覆盖率恢复26.6% |
| 新场景 | 合法场景种子变为2，步数保持0；页面仍暂停 |
| 未实现模型 | U-Net（U-shaped Network）与 DiT（Diffusion Transformer）显示待实现/未加载，选择项禁用 |

界面中的覆盖率和耗时仅为当时画面的观测值，没有按正式协议冻结轨迹，不应汇入评测报告。最后保留页面在暂停状态。

动作队列清空、相邻帧历史重建和模型切换的内部状态，由工程测试覆盖；浏览器检查不以不可见内部状态作为证据。两种扩散骨干尚无实现和权重，因此没有进行真实扩散模型切换。
